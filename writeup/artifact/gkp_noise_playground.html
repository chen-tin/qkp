How these live plots connect to the simulator

All shifts are displayed in units of the lattice spacing L = √π. Each plot compares one seeded path, with identical underlying Gaussian draws for your settings and the reference. The schedule and noise equations follow simulator/nonstationary.py; the last panel runs the nearest-lattice correction loop from simulator/sim.py.

ε₁ = σq,₁ z₁
εₜ = ρₜ (σq,ₜ / σq,ₜ₋₁) εₜ₋₁ + σq,ₜ √(1 − ρₜ²) zₜ
dₜ = εₜ + kickₜ z′ₜ        νₜ = σm,ₜ z″ₜ
x ← x + dₜ;  sₜ = wrap(x + νₜ);  x ← x − sₜ

The shaded bands show ± one standard deviation of the noise distribution, not a confidence interval. The dashed ±½L lines are lattice half-spacing guides; crossing one on a kick alone is not a logical-error diagnosis. The cards report schedule averages, not estimated decoder performance. The JavaScript generator uses a separate seeded random-number stream from the saved Python illustrations, so their individual paths differ. The original figures and 50-round replay remain the saved examples above and below.

Schedule values are bounded as in Python: |ρ| ≤ 0.995, σq ≥ 10⁻⁶ in absolute units, and σm ≥ 0. This view exposes fixed parameter values for one trial; the Python generator can also sample many parameters from ranges across trials. Unseen-condition labels use DRIFT_TRAIN_MIX in training/datasets.py.
