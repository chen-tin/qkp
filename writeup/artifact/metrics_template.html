02 / HOW TO READ THE METRICS

Three measures, three different questions

PL(t)

Error at a particular round

The fraction of trials in the wrong logical state after round t. PL(50) and PL(200) use different horizons. E14 paired horizons also differ between settings; compare decoders at the same setting and horizon.

P̄L

Error averaged over the run

The average of PL(t) over rounds. This is the metric behind the nominal ≈95× improvement. It measures time spent in the wrong logical state and is not an error-per-cycle estimate.

ε

Fitted error per round

Estimated from log(1 − 2PL(t)) before saturation, using the repository’s decay fit. A model-based summary of the curve, rather than a count of logical flips. Fit windows can differ between decoders.

Read the uncertainty label. Seed min–max bands describe variation across trained models. Confidence intervals describe sampling uncertainty. ε ratios have no supplied confidence intervals. Observed zero errors do not prove zero risk. Raw flip rates are deliberately not used as the headline long-run metric because revising decoders can dither after saturation.
